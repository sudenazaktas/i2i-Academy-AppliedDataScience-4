# i2i-Academy-AppliedDataScience-4

This project is a simple machine learning classification project developed with Python and scikit-learn. In this project, the purpose is to import a classification dataset, train two models, and compare their performance by using accuracy score and confusion matrix metrics.

The dataset I chose is the Breast Cancer dataset from scikit-learn. The dataset was divided into training and testing datasets to evaluate models on unseen data. The following two classification algorithms were trained in this project: Random Forest and k-Nearest Neighbors.

Both Random Forest and k-NN were tested on the same test data. According to the results, Random Forest performed slightly better and missed fewer malignant tumor cases. Because missing a malignant tumor is more critical in medical diagnosis, Random Forest was considered the better model for this dataset.
